# Hardware & Power Electronics Specifications

## Measurement Sensor Specifications
- **Transducer:** PZEM-004T v1 Single-Phase AC Multimeter
- **Voltage Range:** 80 - 260 V AC True RMS
- **Current Range:** 0 - 100 A AC True RMS via split-core Current Transformer
- **Active Power:** 0 - 22 kW
- **Frequency:** 45 - 65 Hz
- **Power Factor:** 0.00 - 1.00
- **Isolation:** Optocoupler galvanic isolation between AC sensing and UART logic

## Power Factor Correction Parameters
- Target Power Factor: 0.95
- Reactive power compensation formulas compute required capacitive reactance (µF) for inductive loads or inductance (H) for capacitive loads.
